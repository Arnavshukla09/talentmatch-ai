Privacy Policy

Last Updated: November 25, 2026

1. Data Collection and Usage

TalentMatch AI is a tool designed to match your resume against job descriptions. We respect your privacy and are committed to protecting it. Our service operates with strict data minimization principles:

  • Resumes: PDF uploads are written to a temporary server file for text extraction and scoring; pasted text is processed directly. The temporary file is removed when request processing finishes. Resume text and job descriptions are not intentionally retained or used to train models by this application.
  • Job Descriptions: The job description text is processed alongside your resume and is not permanently stored or linked to you.

2. Data Storage

We do not use databases to store user information, resumes, or job descriptions. If you choose to remember a resume or save a page as a profile, the extension stores extracted resume text in chrome.storage.local on your device until you select Clear Profile or uninstall the extension. It stores text, not the PDF. That text is sent to our API when you request scoring; PDF extraction text is returned to the extension only when remembering the resume is requested.

3. Third-Party Services

When the deployment operator configures a Groq API key, scoring also sends excerpts of the resume and job description, together with matched and missing skills, to Groq to generate coaching feedback. If utilized, data sent to these APIs is subject to their respective privacy policies and is not retained by us.

4. Chrome/Edge Extension Permissions

Our browser extension requires the following permissions:

  • activeTab / scripting: Used to read text from the active page for job description extraction or when you choose Save Page as Resume.
  • storage: Used to keep a resume text profile on your device until you clear it, and to remember your extension theme preference. The theme is also cached in extension-local browser storage for startup and is separate from the website theme.
  • API host access: Allows scoring requests to the TalentMatch API. General access to all websites is not requested.

5. Contact Us

If you have any questions or concerns about this Privacy Policy, please contact the developer at the repository provided on our homepage.
